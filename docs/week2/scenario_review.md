### 2-1. 가중치와 상호작용할 때의 예상 결과

계산값 (Claude, R = Σ w·r × 10, 앱과 같은 스케일). **팀은 아래 표를 보기 전/후에 예상한 결과를 '팀 예상 진술' 칸에 직접 쓴다** (W2 루브릭 '보상 벡터 논리: 팀이 사전 진술').

| 시나리오 | 앱 기본 AFRICA (E.2 S.4 M.2 I.2) R_A / R_B | 슬라이드 예시 AFRICA (E.30 S.35 M.15 I.20) R_A / R_B | 팀 예상 진술 |
|---|---|---|---|
| AF-DP-01 | -0.20 / +2.80 → **B** | +0.50 / +1.90 → **B** | (팀 작성) |
| AF-LB-01 | +1.20 / -0.40 → **A** | +0.55 / -0.05 → **A** | (팀 작성) |
| AF-FN-01 | +0.60 / +0.80 → **B** | +0.15 / +1.15 → **B** | (팀 작성) |
| AF-SV-01 | +1.40 / +0.60 → **A** | +1.75 / +0.10 → **A** | (팀 작성) |

- 4개 시나리오 모두 **B 의 보상 합이 A 보다 크다** (DP −0.3 vs +1.1, LB 0.0 vs +0.3, FN −0.1 vs +0.7, SV +0.2 vs +0.5). AF-DP-01 은 7개 프리셋 모두 B → '자명한 정답' 위험. 팀이 보상 값을 다시 볼 것.
- 4건 모두 'B = moral 준수 vs A = emotion/social 이득' 구조라 시나리오 다양성(개인/집단/규범/정체성 각각 자극) 항목에서 감점 소지.
- 4건 모두 케냐·나이지리아 사례 → 다른 지역(남아공·가나·르완다·북아프리카) 1건 추가 권장.
